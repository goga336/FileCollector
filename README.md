# FileCollector
 
Потокобезопасный класс для сборки файлов из чанков, которые приходят в произвольном порядке, могут пересекаться и дублироваться. Сетевое взаимодействие не реализуется.

## Возможности
 
- Чанки принимаются в любом порядке, с разрывами, пересечениями и дубликатами.
- Один файл может собираться несколькими потоками одновременно.

 
## Сборка и запуск тестов
 
Для сборки проекта требуется компилятор с поддержкой C++17 и CMake 3.20 или новее. Если GoogleTest не установлен в системе, он скачивается при конфигурации, для этого нужен доступ в интернет.
 
```bash
cmake -B build
cmake --build build
cd build && ctest

### Пример использования класса
 
```cpp
#include "file_collector.hpp"
 
FileCollector obj;
obj.CollectFile(1, 10); // Допустим передается файл размером 10 байт
 
obj.OnNewChunk(1, 0, {'A', 'B', 'C', 'D'}); // первые 4 байта (pos = 0)
obj.OnNewChunk(1, 2, {'C', 'D', 'E', 'F'}); // пересекается с предыдущим (начиная с pos = 2)
obj.OnNewChunk(1, 6, {'G', 'H', 'I', 'J'}); // не пересекается с предыдущим
 
if (obj.IsComplete(1)) {
    auto file = obj.GetFile(1);               // A B C D E F G H I J
}
 
uint8_t buf[4];
obj.ReadRange(1, 6, 4, buf);                  // true, buf = G H I J
```
