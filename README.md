# FileCollector
 
Потокобезопасный класс для сборки файлов из чанков, которые приходят в произвольном порядке, могут пересекаться и дублироваться. Сетевое взаимодействие не реализуется.
Чанки принимаются в любом порядке, с разрывами, пересечениями и дубликатами.
Один файл может собираться несколькими потоками одновременно. Предполагается, что содержимое файла не меняется в процессе передачи, то есть пересекающиеся чанки содержат одинаковые данные в общей области.

 
## Сборка и запуск тестов
 
Для сборки проекта требуется компилятор с поддержкой C++17 и CMake 3.16 или новее. Если GoogleTest не установлен в системе, он скачивается при конфигурации, для этого нужен доступ в интернет.

### Сборка
```bash
cmake -B build
cmake --build build
```
 
### Запуск тестов
```bash
cd build && ctest
```

### Пример использования класса
 
```cpp
#include "file_collector.hpp"
 
FileCollector obj;
obj.CollectFile(1, 10); // Допустим передается файл размером 10 байт
 
obj.OnNewChunk(1, 0, {'A', 'B', 'C', 'D'}); // первые 4 байта (pos = 0)
obj.OnNewChunk(1, 2, {'C', 'D', 'E', 'F'}); // пересекается с предыдущим (начиная с pos = 2)
obj.OnNewChunk(1, 6, {'G', 'H', 'I', 'J'}); // не пересекается с предыдущим
 
if (obj.IsComplete(1)) {
    auto file = obj.GetFile(1);               // A B C D E F G H I J
}
 
uint8_t buf[4];
obj.ReadRange(1, 6, 4, buf);                  // true, buf = G H I J
```

## Описание методов

`CollectFile(fileId, fileSize)` — регистрирует файл и создает структуру для сбора чанков.


`OnNewChunk(fileId, pos, chunk)` — добавляет чанк к файлу.

`IsComplete(fileId)` — проверка собранности файла: возвращает `true`, если файл собран целиком, иначе - `false`.

`GetFile(fileId)` — возвращает умный указатель на собранный файл или возвращает`nullptr`, если файл еще не собран.

`ReadRange(fileId, pos, len, outBuf)` — частичное чтение диапазона.

`RemoveFile(fileId)` — удаляет файл из таблицы файлов.


## Хранение данных

Для хранения файла создана структура, позволяющая хранить буфер с байтами файла, маску принятых байт, счетчик уникальных полученных байт и мьютекс для защиты содержимого. Буфер создается сразу при регистрации файла. При приеме чанка данные копируются в буфер, а затем по маске отмечаются новые байты и увеличивается счетчик. Маска принятых байт хранится как вектор булевских значений, поэтому занимает N/8 байт. Файл считается собранным, если счетчик стал равным размеру файла.

Таким образом, можно оценить сложность методов данного класса:
| Операция | Временная | Пространственная |
|---|---|---|
| `CollectFile` | O(N) | O(N) |
| `OnNewChunk` | O(L) | O(1) |
| `IsComplete`, `GetFile` | O(1) | O(1) |
| `ReadRange` | O(L) | O(1) |
| `RemoveFile` | O(1) | O(1) |


## Потокобезопасность

Для обеспечения потокобезопасности класса используется два примитива синхронизации (мьютекса). Один мьютекс защищает хэш-таблицы при поиске, регистрации, удалении файла. Второй мьютекс используется для защиты содержимого конкретного файла. Ситуация взаимной блокировки исключена, так как порядок захвата мьютексов всегда одинаковый.


## Тесты

Тесты написаны с использованием библиотеки Google Test, тесты разделены по файлам:

- `tests/test_base.cpp` — проверка базовых сценариев использования класса
- `tests/test_chunks.cpp` — проверка логики сборки файла из чанков
- `tests/test_errors.cpp` — проверка обработки ошибок
- `tests/test_read.cpp` — проверка чтения файла: полное и частичное
- `tests/test_threads.cpp` — проверка в условиях многопоточности: несколько потоков пишут в один файл; несколько потоков пишут в разные файлы одновременно

cmake -B build
cmake --build build --target doc

## Покрытие тестами 

Для проверки покрытия тестами кода требуется `gcovr`. Его можно установить:
```bash
sudo apt install gcovr
```
Для генерации отчета по покрытию можно использовать:

```bash
cmake -S . -B build-coverage \
      -DCMAKE_BUILD_TYPE=Debug \
      -DCMAKE_CXX_FLAGS="--coverage" -DCMAKE_EXE_LINKER_FLAGS="--coverage"
cmake --build build-coverage

ctest --test-dir build-coverage

gcovr --filter 'src/' --print-summary # отчет в консоли
gcovr --filter 'src/' --html-details cov.html # HTML-отчет
```

Результат измерения покрытия для `src/file_collector.cpp`:
 
| Метрика | Покрыто | Всего | Доля |
|---|---|---|---|
| Строки | 79 | 79 | 100% |
| Функции | 7 | 7 | 100% |
| Ветви | 75 | 99 | 75.8% |
